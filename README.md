# 📖 Giới thiệu

**AI Student Productivity Platform** là hệ thống hỗ trợ học tập và quản lý công việc dành cho sinh viên, kết hợp AI và automation để tối ưu năng suất học tập.

Project tích hợp:

- 📊 Dashboard học tập
- ⏰ Quản lý deadline
- 💰 Theo dõi chi tiêu sinh viên
- 🤖 AI phân loại giao dịch ngân hàng
- 📄 Công cụ tạo CV tự động
- 🧠 Resume parser bằng AI
- 🔍 OCR đọc văn bản từ ảnh
- 📚 Tóm tắt PDF bằng AI
- 🗂 Workflow quản lý tài liệu

Hệ thống phù hợp cho:

- Sinh viên đại học
- Portfolio Fullstack + AI
- Productivity Platform
- AI Document Processing
- Smart Student Assistant
